Component Details

PSF-2.0 Python 3.14

The Python programming language, developed and maintained by the Python Software Foundation. Python serves as the core runtime for the Kolidiscope platform.

Copyright © Python Software Foundation python.org View license

BSD-3-Clause Flask

A lightweight WSGI web application framework for Python. Flask is used to serve Kolidiscope's web application and API layer.

Copyright © Pallets flask.palletsprojects.com View license

BSD-3-Clause scikit-learn

A machine learning library for Python providing simple and efficient tools for data mining and data analysis. Used in Kolidiscope's predictive modeling and data study automation pipelines.

Copyright © The scikit-learn developers scikit-learn.org View license

BSD-3-Clause NumPy

The fundamental package for scientific computing with Python, providing support for large multi-dimensional arrays and matrices. Core numerical computation engine used throughout the Kolidiscope platform.

Copyright © NumPy Developers numpy.org View license

BSD-3-Clause pandas

A fast, powerful, and flexible open source data analysis and manipulation tool. Used extensively in Kolidiscope for data ingestion, transformation, and report generation.

Copyright © AQR Capital Management, Lambda Foundry, Inc., PyData Development Team pandas.pydata.org View license

BSD-3-Clause SciPy

An open source library for mathematics, science, and engineering. Provides advanced statistical functions and optimization routines used in Kolidiscope's data study calculations.

Copyright © Enthought, Inc. & SciPy Developers scipy.org View license

BSD-3-Clause joblib

A set of tools to provide lightweight pipelining and transparent disk-caching of results. Used in Kolidiscope for parallel computing and efficient computation pipelines.

Copyright © joblib Developers joblib.readthedocs.io View license

Apache-2.0 XGBoost

An optimized distributed gradient boosting library. Used in Kolidiscope for high-performance predictive modeling and scoring.

Copyright © XGBoost Contributors xgboost.ai View license

Apache-2.0 Docker

An open platform for developing, shipping, and running applications in containers. Used in Kolidiscope's deployment and infrastructure management.

Copyright © Docker, Inc. docker.com View license

BSD-3-Clause Seaborn

A statistical data visualization library built on Matplotlib. Used in Kolidiscope for generating publication-quality charts and reports.

Copyright © Michael Waskom seaborn.pydata.org View license

PSF-based Matplotlib

A comprehensive library for creating static, animated, and interactive visualizations in Python. Core visualization engine used throughout the Kolidiscope platform.

Copyright © Matplotlib Development Team matplotlib.org View license

Secure Data Upload

Kolidiscope uses SFTP (SSH File Transfer Protocol) to securely transfer data between your organization and our platform. All transfers are encrypted and authenticated.

How It Works

  1. Your Kolidiscope account team provisions SFTP credentials and a dedicated upload directory for your organization.
  2. Connect to the SFTP server using your provided credentials and any standard SFTP client (WinSCP, FileZilla, Cyberduck, or command-line).
  3. Upload your data files to your designated directory. Supported formats include CSV, delimited text files, and common tabular data exports.
  4. Once uploaded, the platform automatically detects, validates, and ingests your data for processing.

Connection Details

Your SFTP credentials and connection details are provided during onboarding. A typical connection looks like:

# Connect via command line
sftp username@sftp.kolidiscope.com

# Or configure your SFTP client with:
Host: sftp.kolidiscope.com
Port: 22
Protocol: SFTP (SSH File Transfer Protocol)
Authentication: SSH key or password

Security

Encrypted Transfer

All data transfers use SSH encryption. Files are never transmitted in plaintext.

Authentication

SSH key-based or password authentication. IP allowlisting available upon request.

Isolated Directories

Each customer has a dedicated, chroot-jailed directory. No cross-tenant access is possible.

Audit Logging

All upload activity is logged with timestamps and user identifiers for full traceability.
